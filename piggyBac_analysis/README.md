# piggyBac Analysis (Part II)

Targeted phylogenetic analysis of the piggyBac transposon (IFP2, J04364.2)
across 5 baculovirus and 4 Lepidoptera host genomes.

**Status:** in progress — files to be added by collaborator.

Expected structure:
- `data/`    — BLAST hits, extracted sequences
- `scripts/` — run_blast_all.sh, extract_hits.sh
- `results/` — alignment_piggyBac.fasta, trimmed_piggyBac.fasta,
               tree_piggyBac.treefile, tree_piggyBac.iqtree, tree_piggyBac.contree
- `figures/` — publication-ready tree
